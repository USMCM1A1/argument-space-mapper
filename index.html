Build your map from your own coding

  1. Start from the course template (button above). Fill in the Matrix tab: one row per source, full sentences for claim, grounds, key warrant and audience.

  3. Download as .xlsx (in Google Sheets: File > Download > Microsoft Excel) and load it here. Each coded dimension becomes a lens.
